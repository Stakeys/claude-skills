# claude-skills

Skills pessoais do Claude Code (Stanley), com backup independente de qualquer projeto específico.

Para instalar numa máquina nova:

```bash
git clone git@github.com:Stakeys/claude-skills.git ~/claude-skills
cp -r ~/claude-skills/* ~/.claude/skills/
```

## Skills

- **mobile-app-bootstrap** — checklist de lições para começar/depurar apps Expo/React Native (versão do SDK, migrações de SQLite, formulários, diagnóstico de travamentos).
